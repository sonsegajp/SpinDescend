# Spin & Descend

A low-poly, slot-machine roguelike. Spin. Fight. Loot. Upgrade. Die. Spin again.

Play: https://sonsegajp.github.io/SpinDescend/

Runs in any WebGL2 browser. Own engine (JavaScript + WebGL2, no libraries).

Controls: arrows / WASD or click to choose a path, SPACE to spin / confirm, TAB reels + paytable, M map, N sound, V CRT filter.

Paylines: 3 matching symbols in a row give a permanent bonus for the run (Might, Guard, Max HP, Fortune, Luck, a Rare+ card, Doom, Kaboom, High Roller, Mega Jackpot). 3 of the same rare symbol in a row (Poison Dagger, Vampiric Vial, Lucky Charm, Mimic Chest, Cursed Skull) adds its own bonus. 3 of a kind anywhere rolls for a bonus that spin (3 Treasure = an extra card). TAB twice shows the paytable.
