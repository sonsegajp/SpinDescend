# Spin & Descend

A low-poly, slot-machine roguelike. Spin. Fight. Loot. Upgrade. Die. Spin again.

Play: https://sonsegajp.github.io/SpinDescend/

Runs in any WebGL2 browser. Own engine (JavaScript + WebGL2, no libraries).

Controls: arrows / WASD or click to choose a path, SPACE to spin / confirm, TAB reels + paytable, M map, N sound, V CRT filter.

Paylines: 3 matching symbols in a row give a permanent bonus for the run (Might, Guard, Max HP, Fortune, Luck, a Rare+ card, Doom). 3 of a kind anywhere on the reels rolls for a bonus that spin (3 Treasure = an extra card).
